# Scout Finance image rights register

No photographic asset may be published until its source, author, licence and approval fields are complete. Files should be supplied in their original resolution; production derivatives will be generated locally as AVIF, WebP and JPEG.

**Generated placeholders.** `scripts/make-placeholder-media.py` writes on-brand generated compositions into `static/assets/images/` for layout review. They are not photography and carry no licence to clear, but they are also not approvable output. `build_site.py` includes them only when `PLACEHOLDER_MEDIA=1`; every default and production build renders the abstract fallback instead.

**AI-generated candidate images (2026-09-04).** Six images generated with ChatGPT image generation were dropped into `static/assets/images/` and processed into the site's responsive derivatives for `hero`, `method`, `international`, `sector-public`, `sector-industry` and `sector-purpose`. These depict **fictional, generative-model-synthesized people and places** — nobody shown is an actual Scout Finance employee, client, or physical office, and no such institution/facility exists as pictured. Before these ship to production:
- Every "Approved" cell below must move from `No` to a real decision — this is a judgment call about representing a professional-services/audit firm with synthetic "documentary" photography, not just a licensing formality.
- If approved, the on-page alt text and any nearby copy must not imply these are real staff, real premises, or real client work.
- `leadership` was deliberately **not** generated — see the row below; it depicts a specific named real person and must not be synthesized.
- Until a row is marked `Approved: Yes`, `build_site.py` must be run without `PLACEHOLDER_MEDIA=1` for any real deploy, and the corresponding files should be removed from `static/assets/images/` before that build — `media_panel()` renders a `<picture>` tag whenever the files are merely present on disk, independent of the flag, so leaving them in place risks a build that emits image markup the deploy step then fails to publish.
